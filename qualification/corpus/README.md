# Qualification corpus

This directory contains small, deterministic models used to compare DuckySlicer's
Android output with the pinned OrcaSlicer engine. The fixtures are generated by
`tools/qualification_corpus.py`; they do not come from third-party model sites.

The manifest fixes the model hashes, effective printer/process/filament inputs,
observable G-code roles, and Preview coverage thresholds. Generate a device report with:

```sh
python3 tools/run_qualification_corpus.py --serial <adb-serial>
```

Use `python3 tools/qualification_corpus.py --check` after editing a fixture. Reports and
G-code are local build evidence and are intentionally not committed.
